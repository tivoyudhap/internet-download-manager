# Project working preferences

## Test planning

- Before writing tests for a feature, first map the plausible cases completely
  based on the feature behavior, boundaries, failure modes, recovery paths, and
  user controls.
- Review the case map against the implementation, then write tests to cover the
  identified cases. Call out any cases that cannot be tested or verified in the
  current environment.
- Do not claim test coverage is complete without showing the scope that was
  mapped and the verification results.
